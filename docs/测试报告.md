# 测试与模型评估报告

## 1. 结论摘要

本报告区分**功能自动化**、**浏览器操作**和**模型实测**。原型的主要项目、画布、保存、导出交互有实际验证；后端专项自动化 41 项通过。真实本地模型证据仅覆盖一个香水瓶样例的 U2Net 抠图，未做统计质量评估。SDXL、ControlNet、BiRefNet 未在当前环境部署。当前文生图连接云端百炼，与产品目标“全部推理在本地完成、无云端兜底”不一致。

## 2. 测试版本、环境与范围

- **版本标识：** AI-Studio 当前工作区快照，2026-10-22；项目无可引用的版本标签。
- **运行环境：** macOS，Apple Silicon/MPS；浏览器布局检查覆盖桌面与 390px 移动宽度。
- **功能范围：** 项目读取/深链、素材上传、本地抠图、图层/旋转持久化、保存快照、任务状态、PNG/JPEG 导出。
- **模型范围：** 本地 U2Net 的单样例运行记录；未对云端 Qwen 生成做本轮调用或质量评估；本地生成模型未部署。
- **方法：** 后端 pytest；前端 lint、TypeScript 与生产构建；浏览器手工操作及持久化/导出检查。自动化测试中的 mock 仅验证业务逻辑，不作为模型输出证据。

| 当前原型云端文生图 | 百炼 API | 不是本地模型证据；本轮未调用，不记录质量/速度结论 |

量化建议为**首轮不量化、先用 FP16 建基线**。INT8/8bit 只有在指定硬件上验证显存收益、兼容性和画质后才考虑；当前无相关测试结果。

### 4.2 已执行的真实本地模型测试

- **模型：** rembg/U2Net，本机推理。
- **样本：** 一张公共领域复古香水瓶实物照片。
- **操作/结果：** 浏览器触发抠图任务，任务完成并生成透明背景素材，可进入画布。证据见[实际 U2Net 抠图产物](./assets/u2net-cutout.png)和[浏览器画布](./assets/editor.png)。
- **结论：** 证明当前设备上的该模型与这一张输入可以跑通；样本数为 1，未有人体标注 mask，无 IoU、耗时、内存、跨品类成功率或人工评分，不能据此宣称抠图质量达标。

SDXL、ControlNet、BiRefNet：**未测试**，原因是模型尚未部署；大型模型权重不包含在此代码库中。云端模型结果不纳入本地模型性能评估。

### 4.3 后续评估设计（待执行，不是测试结果）

**样本与固定条件**

- 初始建议准备 20–30 张合法商品图，覆盖白底图、普通场景和复杂背景，涵盖美妆、食品、数码、家居等品类；抠图样本需提供人工标注边界。
- 为每张商品图准备固定背景提示词，冻结模型权重、硬件、推理后端、随机种子、分辨率和采样配置。
- 记录冷启动与稳定运行耗时，分开记录失败原因、峰值内存/显存；不得把不同设备数据混为一组。

**客观可测指标**

| 指标 | 使用方法 | 当前结果 |
|---|---|---|
| 抠图 IoU / 边界误差 | 与人工标注 mask 对比 | 未测；当前单样例没有标注 |
| 单张耗时、冷启动耗时 | 固定设备/参数，记录多次并报告中位数与范围 | 未测 |
| 峰值内存/显存、失败率 | 运行期间采集资源与错误记录 | 未测 |
| CLIP 图文相关性 | 作为提示词一致性的辅助信号，不能替代人工商品保真判断 | 未测 |
| FID | 仅在有足够且代表性的固定参考图集时比较分布 | 未测；不用于单张样例结论 |
| LPIPS/SSIM | 仅适用于有对应参考图、需比较结构相似性的任务 | 未测 |

**主观评分与拟定目标值**

两名评审盲评，分别按 1–5 分评价：可直接使用程度、真实感、商品形状/颜色/logo 保真、构图留白、文字清晰度。评审样本应随机编号；评分出现较大分歧时复核样例与评分标准。

项目规格中已有的**拟定目标值**为：可用率（可用性评分 ≥4）≥80%，商品保真平均分 ≥4/5；本地 1024×1024 单张耗时目标为开发设备 ≤90 秒、目标工作站 ≤20 秒。以上全部是待验证目标，不是当前实测结果；应在首轮真实本地样例后校准。

## 5. 未验证项目与报告边界

- 本地文生图、ControlNet 与 BiRefNet 未部署；全本地推理目标因此尚未由当前原型证明。
- 真实生成质量、性能、量化效果、抠图 IoU 和多品类主观评分均未验证。
- 浏览器中的 U2Net 取消操作未赶在任务完成前执行；不可把自动化状态机测试写成端到端浏览器取消证据。
- 历史云端生成图或旧耗时不是本轮测试，也不能说明本地模型质量、速度或费用。
